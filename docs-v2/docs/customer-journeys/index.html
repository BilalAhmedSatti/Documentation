In brief — customer journeys
  • Onboarding first. E-money account opens after KYC + screening CLEAR — see account lifecycle.
  • Cash-in = issuance. Physical cash at agent → e-money credit. Cash-out = redemption.
  • Send money is a saga. Quote → screen → hold → payout → settle — state machine in Transaction States.
  • Same invariants everywhere. tenant_id, idempotency keys, integer money, fail-closed screening.
