Step 08 · Activation Gate + Wallet Assignment + TigerBeetle

Presenter cheat sheet
  • Activation Gate: Verification Strength + Pre-screen CLEAR + CDD + EDD (if HIGH).
  • Tracking ID (session) converts to canonical Wallet Number only after gate passes.
  • Money lives in TigerBeetle — not in identity Postgres.
  • BPRD Circular 04 A.viii: 2-hour cooling-off delay on outward transfers immediately after activation.
