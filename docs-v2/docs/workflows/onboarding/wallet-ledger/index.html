Step 08 · Activation + TigerBeetle

Presenter cheat sheet
  • Money lives in TigerBeetle — not in identity Postgres.
  • Wallet metadata is a product shell; balances are ledger accounts.
  • Point at CREATE TigerBeetle as the value system-of-record write.
  • After this, Fund Transfer / Bill Pay workflows can move money.
