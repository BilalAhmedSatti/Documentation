Step 05 · Pre-Screening Gate (UNSC & ATA 1997)

Presenter cheat sheet
  • Pre-screening Moment 1: must run BEFORE eKYC verification.
  • Sanctions match = J5 hard stop (zero tipping-off).
  • Provider failure or timeout = J11 fail closed (VERIFICATION_PENDING).
