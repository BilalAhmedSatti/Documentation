Step 06 · Evidence store + case write

Presenter cheat sheet
  • Binaries are NOT in Postgres — only evidence_ref.
  • PUT object storage + INSERT verification_cases together.
  • Timeout → MANUAL_REVIEW (fail safe).
  • Pack chooses which eKYC provider runs.
