Step 06 · Remote Verification Ladder (Rungs A–D)

Presenter cheat sheet
  • Rung A: NADRA Biometric → Biometric Band (PKR 400,000 monthly load).
  • Rung B: Verisys Bundle (Verisys + SIM pairing + OTP) → Verisys Band (PKR 50,000 monthly load).
  • Rung C: Verisys passed but pairing/OTP failed → DEBIT_BLOCKED state.
  • Rung D: Video KYC / Partner reliance (J4) when remote rungs fail.
  • Binaries stored in object storage — ONLY evidence_ref in PostgreSQL.
