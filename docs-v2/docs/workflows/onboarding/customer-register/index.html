Step 04 · Customer + event writes

Presenter cheat sheet
  • CustomerId is the key forever — quote it when explaining later steps.
  • UNRATED means not risk-scored yet — money limits come after tier.
  • Outbox pattern: write DB first, then publish — no lost events.
  • Two Postgres writes + one bus publish in this step.
