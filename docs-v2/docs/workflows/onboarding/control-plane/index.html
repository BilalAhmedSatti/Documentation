Step 03 · Load the market rulebook

Presenter cheat sheet
  • Say: “Same product code, different market rules from the database.”
  • Pack / rulebook = providers + lists + risk model.
  • This step is mostly a READ, not an INSERT.
  • If rules were hard-coded, every market change would need a code release.

Step-by-step walkthrough
