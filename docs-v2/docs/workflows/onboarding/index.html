Onboarding

Register/login through identity, screening and wallets — every durable commit shown as a DB write on the workflow diagram (PostgreSQL 16, Redpanda, object storage, TigerBeetle).

Ready workflow pack in this documentation set.

Pipeline outcome ACTIVE customer with credentials + profile + risk tier in PostgreSQL, and ledger accounts in TigerBeetle.

Overview

This is the complete path a new retail customer takes. Channel starts the journey, NestJS services do the work, purple nodes show every durable commit.

Cheat sheet

  • Tell the story in one breath: register → credentials → customer → KYC/AML → tier → TigerBeetle.
  • Purple boxes only = what is saved. Grey process boxes = work.
  • Identity Postgres holds profile/tier — never balances.
  • TigerBeetle CREATE at the end is when money accounts exist.

Design companion: ../Docs_Portal/documents/02_Design_Companions/02_identity.design.md (engineering library in Docs_Portal).
